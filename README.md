# Kanban — управление документами

Канбан-доска для организации документов и перемещения их между этапами работы.

## Возможности

- Создание досок и колонок.
- Перетаскивание документов.
- Формы, модальные окна и состояние Redux.

## Инженерные акценты

- Разработка drag-and-drop интерфейса.
- Моделирование состояния доски и пользовательских операций.
- Переиспользуемые компоненты и управление интерактивностью.

## Стек

React, Next.js, TypeScript, Redux Toolkit, Tailwind CSS.

## Навигация по коду
